**E-commerce Review Sentiment Analysis**

**Overview**
A multi-model system to classify e-commerce product reviews as Positive or Negative, using SVM, Bi-LSTM, and DistilBERT. Compare model performance and see predictions with confidence scores.

**Key Features**

Multi-model sentiment analysis: SVM, Bi-LSTM, DistilBERT

Text preprocessing: cleaning, tokenization, and feature extraction

Fine-tuned DistilBERT for contextual understanding

Simple function to test any review and display model predictions and confidence

Compare classical ML, deep learning, and transformer-based approaches

**Tech Stack**

Python, Pandas, NumPy

Scikit-learn, TensorFlow/Keras, PyTorch, Transformers

Concepts: NLP, Sentiment Analysis, Deep Learning, Transformer Models
